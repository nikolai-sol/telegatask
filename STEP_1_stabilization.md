## Задача 1: Запусти проект локально и пройди сценарии

### 1.1 Запуск
```bash
npm install
npm run dev
```

Если есть ошибки при запуске — зафикисруй их и исправь.
Проверь что .env содержит все нужные переменные:
```
TELEGRAM_BOT_TOKEN
GEMINI_API_KEY
GOOGLE_APPLICATION_CREDENTIALS
MINI_APP_URL
```

### 1.2 Пройди каждый сценарий вручную через Telegram

Для каждого сценария запиши: ✅ работает / ❌ падает / ⚠️ работает но не так

**Сценарий 1 — базовый бот:**
- Напиши боту /start
- Напиши боту /help (если есть)

**Сценарий 2 — создание тендера:**
- /tender new Тестовый тендер
- Получил ли ответ с кнопками?
- Кнопка "Открыть в приложении" — открывается ли Mini App?

**Сценарий 3 — создание кампании:**
- /campaign new Тестовая кампания
- Работает аналогично тендеру?

**Сценарий 4 — быстрая задача:**
- /task Протестировать бота
- Появилась ли кнопка Fire / Done?

**Сценарий 5 — AI:**
- /ask Что такое медиаплан?
- Отвечает ли Gemini?
- Сколько секунд занимает ответ?

**Сценарий 6 — knowledge:**
- /k Тестовая заметка
- /ksearch тест
- Находит ли что добавили?

**Сценарий 7 — Mini App:**
- Открой Mini App через бота
- Загружается ли?
- Видны ли задачи / компании?
- Есть ли ошибки в консоли браузера?

## Задача 3: Почини всё что сломано

Приоритеты починки:

**Критично (без этого нельзя работать):**
- Бот не запускается
- /start не отвечает
- Mini App не открывается
- Firestore не подключается

**Важно (мешает использовать):**
- Команды падают с ошибкой
- AI не отвечает
- Mini App открывается но пустой

**Некритично (можно потом):**
- Медленные ответы
- Некрасивый текст в сообщениях
- Отсутствующие иконки

---

## Задача 4: Один критический баг который нужно проверить

В `src/handlers/file.handler.ts` есть вызов:
```typescript
const fileLink = await bot.telegram.getFileLink(fileId);
```

Проблема: `bot` может быть недоступен в контексте handler.
Проверь что объект `bot` или `ctx.telegram` передаётся корректно.
