Данные для проверки после деплоя. Чтобы не потерять — держим здесь.

## Что означало сообщение «Принял запрос на дайджест. ИИ-дайджест будет подключён позже.»

Это **заглушка** из старого кода (`handleDigest` в telegataskBot.ts). Появлялась, когда команда `/digest` обрабатывалась legacy-хендлером, а не skill.

**Сейчас** digest реализован как skill (`src/skills/digest/`). Skill роутер должен обрабатывать `/digest` и `/дайджест` первым. Если видишь эту заглушку — значит skill по какой-то причине не сработал (старая версия без деплоя или ошибка).

## Digest — что проверить

### Перед проверкой

- [ ] Бот задеплоен (последняя версия с digest skill)
- [ ] В `.env` есть `GEMINI_API_KEY` (для AI-дайджеста)
- [ ] Бот добавлен хотя бы в один групповой чат
- [ ] В чате есть сообщения (сохранены в `messages`)
- [ ] Есть задачи с `sourceChatId` этого чата
- [ ] Есть knowledge с `importance: important` или тегом `important`

### Команды

| Действие | Команда | Ожидаемый результат |
|----------|---------|---------------------|
| Digest в группе | `/digest` или `/дайджест` | Сводка по текущему чату за сегодня |
| Digest за вчера | `/digest yesterday` | Сводка за вчера |
| Digest за неделю | `/digest week` | Сводка за последние 7 дней |
| Digest в личке | `/digest` | «Выберите чат» + кнопки с чатами |

### Лимиты (free)

- [ ] Digest: 2 раза в месяц на free
- [ ] При превышении: «Лимит исчерпан... Перейдите на Pro»

### Русские команды

| EN | RU | Проверить |
|----|-----|------------|
| `/digest` | `/дайджест` | Оба варианта работают |
| `/k` | `/знания`, `/в_знания` | Оба работают |
| `/ask` | `/спроси`, `/вопрос` | Оба работают |
| `/ksearch` | `/поиск` | Оба работают |

## Knowledge — что проверить

- [ ] `/k текст` — сохраняет note
- [ ] `/k` в reply на сообщение — сохраняет message
- [ ] `/k` на пересланный файл — сохраняет file_ref
- [ ] Повторный `/k` на тот же источник — «Уже в базе»
- [ ] «это важно» после forward — сохраняет с тегом important

---

## Кнопки (Save / Task / Open)

- [ ] В ответе `/ask` и `/ksearch` есть кнопки Save, Task, Open
- [ ] `kb:save` — «Уже в базе» или подтверждение
- [ ] `kb:open` — ссылка или «chat X / msg Y»
- [ ] `task:create` — создаётся задача
- [ ] Чужой knowledgeId из другого чата → «Нет доступа»

---

## Scope / guard

- [ ] Кнопка Save/Task/Open на чужой записи (другой чат/пользователь) → «Нет доступа»

---

## Общее

- [ ] `pm2 status` — telegatask online
- [ ] `pm2 logs telegatask` — нет критических ошибок
- [ ] `curl http://localhost:3000/health` — 200
- [ ] Firestore indexes задеплоены (`firebase deploy --only firestore:indexes` при необходимости)

---

## Когда всё проверить

1. **Сразу после деплоя** — базовая проверка команд и кнопок.
2. **После смены GEMINI_API_KEY** — /ask и /digest.
3. **После изменений в permissions/guard** — доступ к чужим записям.
4. **В начале месяца** — лимиты usage сброшены (free).
