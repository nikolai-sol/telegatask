# Feature Plan

Дата: 2026-02-13

## Bot: Project Management (v1)

### Goals
- Управлять проектами полностью из бота (без ручных команд вида `/setproject <id>`).
- Wizard на кнопках: создание проекта, привязка к чату, управление доступом.

### Done
- `/project_manage` (skill `project-admin`):
  - Создание проекта: имя/описание.
  - Привязка проекта к текущему чату (и опционально установка дефолтного проекта чата).
  - Экран “кто видит проект” + выбор участников через поиск по участникам команды.

### Next
- Редактирование проекта (name/desc) из этого же wizard.
- Отвязка проекта от чата (и снятие defaultProjectId).
- Пагинация списков проектов/участников (если > 12 / > 10).
- Отдельный “project settings” экран: связанные чаты, статистика, владельцы.

## Bot: “Емеля” Mode (voice-first project kickoff)

### Idea
Кнопка “Емеля” запускает режим, где голосом можно:
- “мы начинаем проект …” -> бот создает проект
- “добавь команду …” -> добавляет участников (из списка/поиска)
- “обсудим задачи” -> совместно формирует список задач (и создает их)
- “закрыть проект” -> фиксирует статус/архивирует/отключает активность

### Planned Implementation
- Команда `/emelya` + кнопка “Емеля” в reply keyboard.
- Поддержка voice messages:
  - STT (speech-to-text) для распознавания
  - LLM для извлечения структурированных команд (create_project/add_members/create_tasks/close_project)
  - Audit log каждого действия
- Ограничения безопасности:
  - только owner/admin команды
  - подтверждения на destructive actions (delete/close)

### Open Questions
- STT провайдер (Telegram native? внешний сервис?) и стоимость.
- Модель/провайдер LLM и лимиты.
- Что значит “закрыть проект” в данных: поле status + архивирование задач/доступов?
