# План: Индексация содержимого файлов

> Реализовать позже. Документ обновляется по мере появления идей.

---

## Что уже есть

- **file_ref** — сохраняем ссылки на файлы (file_id, fileMeta), не скачиваем
- **Auto-save** — файлы, которые ты постишь в чатах, автоматически попадают в knowledge
- **Поиск** — /ksearch и /ask ищут по полю `text` (имя, caption, meta)

---

## Цель: поиск по содержимому файлов

Чтобы /ksearch и /ask находили PDF, Word, изображения с текстом — нужно извлекать текст из файлов и индексировать.

---

## Этапы реализации

### 1. Скачивание файлов из Telegram

- Использовать `bot.telegram.getFile(file_id)` → получить `file_path`
- Скачать с `https://api.telegram.org/file/bot<token>/<file_path>`
- Хранить во временной папке или в памяти (Buffer)
- Ограничение Telegram: до 20 MB для бота

### 2. Парсинг по типам

| Тип | Расширение | Инструмент | Зависимость |
|-----|------------|------------|-------------|
| PDF | .pdf | pdf-parse, pdfjs-dist | pdf-parse |
| Word | .docx | mammoth | mammoth |
| Текст | .txt | — | встроено |
| Изображения | .png, .jpg | OCR | tesseract.js или Google Vision API |
| Excel | .xlsx | xlsx | xlsx |

### 3. Обновление модели knowledge

- Добавить поле `extractedText?: string | null` — извлечённый текст
- При добавлении file_ref:
  - Скачать файл
  - Распарсить → extractedText
  - text = fileText + (extractedText ? "\n" + extractedText) — для поиска
- Или хранить отдельно и объединять при поиске

### 4. Асинхронная индексация

- Синхронное скачивание и парсинг может быть медленным (PDF 10 MB)
- Вариант: отложенная индексация (Cloud Function / отдельный воркер)
- Сразу сохраняем file_ref с пустым extractedText
- Cron или event-driven: берём file_ref без extractedText → индексируем → обновляем

### 5. Лимиты и квоты

- Лимит размера файла для индексации (например, 5 MB)
- Ограничить типы (только PDF, DOCX, TXT)
- rate limit на запросы getFile

---

## Риски

- Парсинг PDF — разный результат в зависимости от структуры (скан vs текст)
- Большие файлы — таймауты, память
- Стоимость: Google Vision для OCR платный

---

## Приоритет

```
1. PDF + DOCX + TXT (без OCR)     ← начать с этого
2. Ограничение 5 MB
3. Синхронная индексация при добавлении
4. OCR для изображений             ← позже, дороже
5. Асинхронная очередь             ← если синхронно тормозит
```

---

## Связанные идеи (на потом)

- **Voice messages** — распознавание речи (Telegram → audio file → Whisper API)
- **Веб-страницы** — при сохранении ссылки парсить content (puppeteer / cheerio)
- **Векторный поиск** — embeddings для semantic search (не только keywords)
