DECISION

Есть база для SEO и GEO. Главная задача — выйти за пределы бренда.

У Stresshelp.ru есть тесты, консультации и материалы специалистов. В проверенной выборке сайт уверенно находится по своему названию, но почти не встречается по вопросам людей о тревоге и стрессе. Предложение должно соединить точный медицинский интент → подходящую страницу → доверие к источнику → целевое действие.

Главная возможность роста: «панические атаки». Wordstat возвращает 322 565 запросов за 30 дней для этого широкого кластера. Stresshelp.ru не найден в первых 50 документах по проверенной фразе. Начать с понятной пациентской страницы, экспертной проверки и связанных вопросов; сначала оценить существующие материалы, затем решать, какую страницу обновлять. Это потенциал спроса, не прогноз посещений.

Широкое слово «тревога» нельзя использовать как чистый медицинский рынок: в нём много сигналов тревоги, новостей и музыкального контента.

REGIONS

Где относительный интерес выше медианы

Для каждого запроса сравнивается его доля во всех поисках региона. Коэффициент = доля в регионе / медианная доля сопоставимых регионов. 1,70× означает интерес на 70% выше медианного, с поправкой на общий размер поисковой активности региона.

В таблице — коэффициент не ниже 1,50× и минимум 100 запросов за 30 дней. Это порог для приоритизации, не статистическая значимость.

Покрытие и проверяемость

  • Wordstat: 20 исходных фраз; спрос за 30 дней, региональное распределение, 24 полных месяца динамики. Первичная проверка не приняла шесть ответов с опущенными полями; повторные ответы сохранены отдельно. Подтверждены totals 2/3/5 по трём вариантам бренда; отсутствующие месячные count не используются в выводах.
  • Search API: 40 запросов, 38 списков документов; два пустых ответа оставлены пропусками.
  • Generative Search API: 36 вызовов, 35 ответов, один HTTP 500. Брендовый вопрос учитывается отдельно.
  • Всего выполнено 143 обращения к Яндекс API при согласованном потолке 152: Wordstat 67, поиск 40, генеративный поиск 36. Pixel Tools — отдельный дополнительно согласованный источник.

  • Нет доступа к фактическим показам, кликам и конверсиям сайта. Семантика Wordstat и поисковые проверки не заменяют эти данные.
